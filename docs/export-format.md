# Формат файла экспорта карточек

«Ещё → Обмен карточками → Экспорт» сохраняет выбранные карточки в один JSON-файл, «Импорт» раскладывает его по папкам своего репозитория. Файл можно передать другу любым способом: почтой, в мессенджере, на флешке.

```json
{
  "format": "culture-diary-export",
  "version": 1,
  "exported_at": "2026-11-08T22:40:00.000Z",
  "cards": [
    {
      "section": "concerts",
      "slug": "placebo-2026-11-04",
      "fields": {
        "artist": "Placebo",
        "support": "Maria Iskariot",
        "venue": "Hallenstadion, Zürich",
        "spotify": "https://open.spotify.com/artist/6RZUqkomCmb8zCRqc9eznB",
        "date_attended": "2026-11-04"
      },
      "summary": ""
    }
  ]
}
```

| Поле | Что это |
|---|---|
| `format` | всегда `culture-diary-export` |
| `version` | версия формата; приложение отказывается читать файл новее себя |
| `exported_at` | когда сделан экспорт, ISO 8601 |
| `cards[].section` | папка в репозитории: `books`, `movies`, `concerts`, `theatre`, `exhibitions`, `lectures` |
| `cards[].slug` | имя файла без `.md` |
| `cards[].fields` | фронтматтер карточки в том же виде, что в `.md` (строки; списки через запятую) |
| `cards[].summary` | текст раздела `## Резюме` в markdown, может быть пустым |

## Что не экспортируется

Раздел `## Отзыв` и `rating` не попадают в файл никогда. Кроме них отрезаются личные поля:

| Раздел | Личные поля |
|---|---|
| книги | `media`, `source`, `date_started`, `date_finished`, `date_abandoned`, `abandoned_at` |
| фильмы | `date_watched`, `where_watched`, `abandoned` |
| концерты, театр, выставки, лекции | нет: дата и площадка общие для всех, кто был на мероприятии |

Импорт отбрасывает эти поля, даже если их дописали в файл вручную.

## Как импорт ищет совпадения

Карточка из файла считается той же, что уже есть в дневнике, если совпадает имя файла в том же разделе или ключевые поля:

| Раздел | Ключ |
|---|---|
| книги | автор + название (или оригинальное название) |
| фильмы | идентификатор IMDb, либо название (или оригинальное) + год |
| концерты | артист + дата |
| театр, выставки, лекции | название (или оригинальное) + дата |

Сравнение идёт по транслитерированной форме без регистра и диакритики, как в именах файлов.

Для совпавшей карточки можно выбрать:

- **Пропустить**: файл не меняется.
- **Дополнить**: заполняются только пустые поля и пустое Резюме, теги объединяются.
- **Заменить**: поля и Резюме берутся из файла (пустое Резюме в файле своё не стирает), теги объединяются.

Оценка, отзыв и личные поля получателя не меняются ни в одном из вариантов. Все карточки записываются одним коммитом `Import N cards`.
