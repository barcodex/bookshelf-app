# Changelog

## [0.4.0] — 2026-07-30

### Три секции таймлайна
- Секция «Сейчас читаю» — книги с `date_started` без `date_finished`, отображаются первыми
- Секция «Прочитал раньше» — книги без обеих дат, в алфавитном порядке по автору
- Фоновая проверка SHA на каждый фокус вкладки Timeline и Search
- Инкрементальное обновление кэша: загружаются только изменённые файлы
- Проверка SHA не запускается на вкладках «Добавить книгу» и «Настройки»

## [0.3.0] — 2026-06-29

### i18n, тема и деплой
- Локализация на 6 языков: русский, английский, немецкий, французский, испанский, итальянский
- Экран выбора языка при первом запуске
- Тёплая бумажная тема для веба (`warm paper`), адаптивные цвета для нативных платформ
- Рендеринг `summary` и `review` как Markdown в карточке книги
- Иконки типа носителя (бумажная, аудио, электронная)
- Кликабельные теги — переход на поиск с предустановленным фильтром
- GitHub Actions: автодеплой на Vercel при пуше в `main`
- Деплой: https://bookshelf-app-xi.vercel.app

## [0.2.0] — 2026-06-01

### Надёжность и производительность
- Compare API для батчевой загрузки: только изменённые файлы при обновлении
- Миграция кэша с `localStorage` на `IndexedDB`
- Таргетированное обновление книги в кэше при сохранении (без полной перезагрузки)
- Обработка ошибок GitHub API с отображением в UI
- CORS-прокси через `/api/github` для веб-платформы

## [0.1.0] — 2026-05-29

### Первый релиз
- Таймлайн книг, сгруппированный по годам, с градиентными заголовками секций
- Статистика носителей и количество книг в заголовке каждого года
- Поиск с дебаунсом, фильтрами по медиа и тегам
- Поля `tags`, `rating`, `media` в форме добавления книги
- Кэш на основе SHA последнего коммита, опрос при каждом открытии
- Экран настроек: GitHub PAT и репозиторий
- Onboarding: экраны объяснения работы с приватным репозиторием

## Roadmap

### Публикация в WordPress
Возможность публиковать отзывы из карточек bookshelf в блог `knigoschet.wordpress.com` — в обратную сторону от текущего импорта постов в карточки. WordPress.com поддерживает REST API с аутентификацией через Application Password (аналогично GitHub PAT). Реализация: кнопка «Опубликовать в блог» в карточке книги, которая берёт `review`, форматирует как пост и отправляет через API.
